# 实验二设计快照

本目录的7份 puml 和7份 PNG 原样复制自实验二 UML，便于按实验三的 UML/code 结构整理提交。
PNG 与源文件逐字节核对未变更；未为本轮验收重画设计。

当前代码已实现商品图片/封面/交付地点、普通终止审批、违规处置及解除、关键操作日志、通知持久队列与后台重试、既有对象写操作的预期版本校验。

原提交预约序列图明确“用户响应不等待通知”。最终验收修复同步钩子：notification_worker.py在同进程后台扫描JSON，慢投递在共享业务锁外，重启无请求重试和去重已补回归。

仍有设计差异：无统计、定期备份与整库恢复；用户以username关联而非独立userId；实体采用JSON字典与模块路由；多进程共享JSON不支持；性能、真人易用性及浏览器指定视口未验收。完整逐项矩阵见 ../code/ACCEPTANCE.md，不把设计快照当作全需求均已实现的证明。
